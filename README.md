# YuvaIntern_week-2
Created informative data visualizations using R and ggplot2 with the Iris dataset. Developed bar charts, scatter plots, histograms, box plots, and line charts to identify patterns, relationships, and trends. Interpreted the visual insights and documented the analysis for clear communication.

## Dataset
The Iris dataset was used for this project. It contains 150 observations from three species:
- Setosa
- Versicolor
- Virginica

The dataset includes sepal length, sepal width, petal length, and petal width.

## Tools and Technologies
- R Programming
- ggplot2
- Iris Dataset

## Visualizations
The following visualizations were created:
- Bar Chart
- Scatter Plot
- Histogram
- Box Plot
- Line Chart

## Key Insights
The visualizations helped identify differences between iris species and relationships between different flower measurements. Petal length and petal width showed particularly clear differences between species.
